# local-note

**日本語** | [English](README.md)

ローカルPCだけで動く、**Notion風のデスクトップノートアプリ**（Electron製・自分専用）。
クラウドには一切送信せず、データは手元の Markdown ファイルとして保存されます。

```bash
npm install     # 初回のみ
npm start       # 起動
```

`.app` として使う場合:

```bash
npm run pack
```

`dist/mac-arm64/local-note.app` ができます。`/Applications` にコピーすればふつうのMacアプリとして常用できます。

既定では**署名なし**でビルドします。自分の Developer ID で署名するときは、証明書の名前を環境変数で渡してください。

```bash
CSC_NAME="あなたの名前 (TEAMID)" npm run pack
```

アイコンを焼き直すときは `npm run icon`（詳しくは `build/icon-source/README.md`）。

### テスト

```bash
npm test       # ブロック ⇄ Markdown の往復と、URLの無害化
npm run check  # 全ソースの構文チェック
```

push と pull request で自動実行されます（`.github/workflows/ci.yml`）。

ブラウザで見た目だけ確認したいときは、`renderer` を配信して開いてください
（例: `python3 -m http.server -d renderer`）。`dev-mock.js` が保存APIの代わりに入り、
ページは localStorage に持ちます。配布物には含まれません。

### 配布用（公証済み dmg）

ネット経由で配ったアプリは、Apple の公証（notarization）を通していないと macOS が開いてくれません（「壊れているため開けません」と出ます）。人に渡すビルドはリリーススクリプトを使ってください。アプリの署名→公証→dmg 化→dmg の公証→両方のステープルまでやります。

```bash
cp scripts/release.env.example scripts/release.env   # 自分の値に書き換える
security add-generic-password -a "<Apple ID>" -s local-note -w   # アプリ用パスワード
scripts/release-mac.sh
```

`dist/local-note-<版>-arm64.dmg`（Apple シリコン）と `dist/local-note-<版>.dmg`（Intel）ができ、
他の Mac でも警告なしで開けます。`scripts/release.env` は git 管理外、アプリ用パスワードはキーチェーンの中なので、どちらもリポジトリには入りません。

公証には有料の Apple Developer アカウントが必要です。無くても `npm run pack` で自分の Mac 用のアプリは普通に作れます。

## 画面と操作感

Notion のエディタ挙動に寄せてあります。

### ブロックエディタ
- **`/`** でブロックメニュー。最近使ったブロックが上に出て、`/削除` `/複製` のような操作も打てます（ページ / テキスト / 見出し1〜3 / 箇条書き / 番号付き / ToDo / トグル / 引用 / コールアウト / コード / 区切り線 / テーブル / 画像 / ページへのリンク）
- **`/page`** でその場に子ページを作成。名前をその場で入力でき、クリックすると中に入れます（サイドバーにも子として並びます）
- ブロックの左に出る **＋**（下にブロック追加＋メニュー）と **⠿**（ドラッグで並べ替え、クリックでブロックメニュー）
- **テキストを選択すると書式バー**が浮く（変換 / **B** / *I* / <u>U</u> / ~~S~~ / `code` / リンク）
- **ドラッグで複数ブロックを選択** → まとめて削除・複製・コピー・インデント
- `Esc` でブロック選択、`Shift+↑↓` で選択を拡張、`⌘A` 2回で全ブロック選択
- **⌘Z / ⌘⇧Z** はブロックの追加・削除・並べ替えまで含めて取り消せます
- 右クリックでブロックメニュー

### 入力ショートカット（行頭で打つと変換）
| 入力 | 変わるブロック |
| --- | --- |
| `# ` `## ` `### ` | 見出し1〜3 |
| `- ` `* ` | 箇条書きリスト |
| `1. ` | 番号付きリスト |
| `[] ` | ToDo |
| `> ` | トグルリスト |
| `\| ` `" ` | 引用 |
| `[]` | ToDo（スペース不要） |
| `a. ` `i. ` | 番号付きリスト |
| ` ``` ` | コードブロック |
| `---` | 区切り線 |

### 書きながら変換されるインライン記法
`**太字**` / `*斜体*` / `~打ち消し~`（`~~`も可） / `` `コード` `` は閉じた瞬間に書式へ変わります。

### サブページ
- `/page` → 子ページが1行のブロックとして入り、そのまま名前を入力できます。クリックでそのページへ移動
- 既存のテキストブロックは、⠿ メニューの「ページに変換」でそのままページにできます
- ⠿ メニューから「名前を変更」「このページを開く」
- ファイル上は `[タイトル](p_xxxxxxxxxxxx.md)` という相対リンクとして保存されるので、他のMarkdownエディタでもページを辿れます
- ブロックを削除してもページ自体は残ります（消すときはサイドバーの ⋯ → ゴミ箱に入れる）

### ページのリンク
- **`[[`** または **`@`** でページ検索ポップアップ。選ぶとそのページへのリンクが入ります（なければその場で新規作成）

### キーボード
| キー | 動作 |
| --- | --- |
| `⌘P` / `⌘K` | ページ検索・作成 |
| `⌘N` | 新規ページ |
| `⌘⇧N` | 子ページを追加 |
| `⌘S` | 即保存（ふだんは自動保存） |
| `⌘\` | サイドバーの表示/非表示 |
| `⌘D` | ブロックを複製 |
| `⌘⏎` | ToDoのチェック / トグルの開閉 |
| `Tab` / `⇧Tab` | 階層を下げる / 上げる |
| `⌘⇧E` | Markdownで書き出し |

## 保存のしかた

ページは1ページ＝1ファイルの Markdown です。

**初回起動時に保存先フォルダを聞かれます。** 既定の候補は `~/local-note/` ですが、Dropbox や iCloud Drive の下、Gitリポジトリの中など、好きな場所を選べます。既にメモの入ったフォルダを選んだ場合は、新しく作らずにそのまま開きます（別のMacから持ってきたフォルダをそのまま使えます）。選ばずにウィンドウを閉じた場合は、何も作らずに終了します。

```
~/local-note/
├── pages/p_xxxxxxxxxxxx.md
└── files/              # 貼り付けた画像
```

> 既定がホーム直下なのは、**書類・デスクトップ・ダウンロードの下は macOS の保護対象**だからです。そこを保存先にすると、システム設定でアプリに「ファイルとフォルダ」の許可を与えるまで、起動時に読み取りエラーになります。

```markdown
---
id: p_1a2b3c4d5e6f
title: 週次メモ
icon: 🗒️
parent: p_0123456789ab
tags: 仕事, 議事録
favorite: false
trashed: false
order: 1762900000
created: 2026-11-12T10:00:00+09:00
updated: 2026-11-12T10:30:00+09:00
---
## やること

- [ ] 見積りを出す
- ▸ トグル
  中身
```

ふつうの Markdown なので、他のエディタで開く・`grep` する・`git` で履歴を残す、どれも自由です。
保存先はあとから **メニュー › local-note › データフォルダを変更…** で変えられます（中身の引っ越しはFinderで行ってください）。

## そのほか

- サイドバーはドラッグで幅を変更、ページはドラッグ&ドロップで入れ子に移動
- お気に入り（★）、タグ、ゴミ箱（復元つき）
- テーマはメニュー › 表示 › ライト / ダーク / システムに合わせる
- 画像は編集中に `⌘V` で貼り付けると `files/` に保存されます

## 制限

- ブロックの文字色・背景色（Notionのカラー）は未対応です。Markdown で表現できないため見送っています
- データベース／ボード／カレンダーのビューはありません。あくまでドキュメント用です
- 同期はしません。必要なら保存先フォルダ自体を同期サービスに置いてください

## 構成

```
local-note/
├── main.js            # Electron メインプロセス（ファイル保存・メニュー・ウィンドウ）
├── preload.js         # contextBridge で渡す保存API
├── renderer/
│   ├── index.html
│   ├── styles.css     # Notion準拠のデザイン
│   ├── markdown.js    # ブロック ⇄ Markdown 変換
│   ├── editor.js      # ブロックエディタ本体
│   ├── app.js         # サイドバー・検索・ページ管理
│   └── dev-mock.js    # ブラウザで見た目確認するときだけ使うモック（配布物には入らない）
├── test/
│   └── markdown.test.mjs  # ブロック ⇄ Markdown の回帰テスト
├── scripts/
│   └── release-mac.sh # 配布用 dmg の署名・公証
└── package.json
```

セキュリティ設定は `contextIsolation: true` / `nodeIntegration: false` / CSP あり。ネットワークへ出るコードはありません。
